# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-07

### Added

- Initial public release of @pokujs/scope-hooks.
- Generic scope-hook lookup helpers keyed by Poku's exported runtime symbol.
- Provider composition with deterministic order and name-based deduplication.
- Compatibility, lint, build, publish, and CodeQL workflows.
